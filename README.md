# Minecraft-server-on-D70
Ich möchte hier den Aufbau meines Minecraft-Servers zeigen.Viele Menschen haben versucht,einen Server im lokalen Netzwerk einzurichten.Der Aufbau des Servers ist nicht sehr kompliziert,aber es gibt einige Herausforderungen bei der Netzwerkkonfiguration.Wie kann man den Server aus dem Internet erreichen?
Für den Zugriff aus dem Internet kommen beispielsweise ein VPN, eine Portweiterleitung über eine öffentliche IP-Adresse oder ein Reverse-Tunnel infrage. Ich habe mich für einen Reverse-Tunnel entschieden, weil meine Freunde dafür keinen VPN-Client benötigen und meinem Anschluss keine öffentlich erreichbare IPv4-Adresse zur Verfügung steht.
Zuerst schauen Sie die Umgebung.Ich habe einen D70-Mini-PC als Proxmox-VE-Host,Debian 13 aks virtuelle Maschine,ein MacBook mit macOS für die Verwaltung per SSH und die Dateiübertragung.
Wenn ich Debian 13 in einer virtuellen Maschine installiere,habe ich der virtuellen Maschine vier CPU-Kerne,8.00GiB RAM und 32GB virtuellen Festplattenspeicher zugewiesen.Diese Ressourcen reichen für einen kleinen Minecraft-Server aus.
Dann muss ich eine statische IP-Adresse für den Server festlegen,weil der DHCP Server jeder IP-Adresse ändern wird.Wenn der externer TCP-Port der innere IP-Adresse eines Server nicht finden kann,wird der Server nicht erreichbar sein.
Ich möchte Minecraft Java Edition in der Version 26.3 spielen,deshalb installiere ich Java 25 auf dem Server.Danach habe ich das Dienstkonto minecraft und das Serververzeichnis /srv/minecraft angelegt.Anschließend habe ich den Eigentümer und die Zugriffsrechte festgelegt, damit der Server unter diesem Konto ausgeführt werden kann.
Das Serververzeichnis enthält paper.jar,server.properties,eula.txt und den Weltordner.
Nachdem ich den Server im lokalen Netzwerk erfolgreich getestet hatte, habe ich den Zugriff aus dem Internet eingerichtet. Zunächst habe ich playit.gg verwendet. Die Latenz war jedoch zu hoch. Deshalb habe ich mit ChmlFrp einen TCP-Tunnel eingerichtet, der Verbindungen vom öffentlichen Port 39500 an den lokalen Port 25565 weiterleitet.
Für den Testbetrieb habe ich die Whitelist und die Online-Authentifizierung deaktiviert.
Abschließend habe ich einen lokalen Spielstand auf den Server übertragen und in der Konfiguration als aktive Welt festgelegt.
Das ist alles,was ich mit diesem Projekt gearbeitet habe.Ich hoffe, dass meine Erfahrungen anderen beim Aufbau eines eigenen Servers helfen können.
